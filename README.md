# Testudy-fuck

TESTUDYで使用されるDigCBTの回答入力・採点・次の問題への移動を自動化する、非公式のChrome拡張機能です。

## インストール

1. このリポジトリを **Code → Download ZIP** からダウンロードして展開します。
2. Chromeで `chrome://extensions/` を開き、**デベロッパーモード**を有効にします。
3. **パッケージ化されていない拡張機能を読み込む**から、`manifest.json` があるフォルダを選びます。
4. 通常どおりログインして取り組む練習を開き、ページ右下または拡張のポップアップで **開始** を押します。

インストール時のビルドや開発ツールは不要です。更新時は拡張機能の再読み込みボタンを押し、問題ページも再読み込みしてください。

## 機能

| 問題・画面 | 動作 |
| --- | --- |
| 選択問題 | 正答の選択肢をクリックして採点 |
| 文字・語句の並べ替え | カードを順番に選択して確定 |
| 入力問題 | 回答を入力して採点 |
| 発話評価 | 生成した雑音を送信して評価を進行 |
| 練習開始・途中の結果 | 開始・次の練習への移動 |
| 最終の成績開示 | **自動実行を停止し、その画面を表示したままにする** |

実行状態はタブごとに管理します。ポップアップを閉じても動作を続け、同じタブでのページ移動にも追従します。新しいタブやブラウザ再起動後は停止状態になります。

手入力済みの回答、不正解判定、画面と問題データの不一致を検出すると停止します。手動の回答が残っている場合は、入力を空にするかサイトのリセット操作をしてから再開してください。停止する前にサイト側で予約された採点やページ移動は、実行される場合があります。

## 設定

ポップアップから変更できます。設定はブラウザ内に保存されます。

| 設定 | 初期値 |
| --- | --- |
| 操作間隔 | 1.2秒（0.5〜5秒） |
| 練習の開始ボタンを押す | ON |
| 練習結果から次へ進む | ON。最終成績では停止 |
| 問題を読む間を取り、録音の長さに幅を持たせる | ON |
| 発話評価に生成した雑音を送信 | ON |
| 雑音の種類 | ざわつき（標準） |
| 生成音声の長さの目安 | 8秒（3〜20秒） |

発話評価の自動処理をOFFにすると、手動の発話を待ちます。雑音には標準のざわつき、連続ざわつき、打音の3種類があります。評価はサイトから返された結果を使用し、点数の書き換えや低得点時の自動再挑戦は行いません。合格点を保証するものではありません。

## 仕組みと送信データ

ブラウザに読み込まれた問題データを参照し、サイトの入力欄・ボタン・採点処理を使って回答します。問題音声の再生や、文量に応じた待ち時間を挟んで操作します。

発話評価では、実際の録音待機時間に合わせた16kHz・モノラルのPCM WAVを生成し、サイトが使用するMicrosoftの音声評価サービスに送信します。実マイクでの録音や、生成音声のスピーカー再生は行いません。サイトの問題音声は通常どおり再生されます。送信時刻や採点結果はサイト側の処理を使用します。

拡張が保存するのは設定、タブごとの実行状態・最新の処理状態、直近30件の操作ログです。問題の回答は処理状態として一時的に保持されます。操作ログには回答本文や認証情報を含めません。学習結果や生成音声は、通常のサイト操作と同様に各サービスへ送信されます。

| 拡張権限 | 用途 |
| --- | --- |
| `storage` | 設定・実行状態・操作ログの保存 |
| `scripting` | 問題ページ内での操作 |
| `activeTab` | ポップアップで操作中のタブを取得 |
| `www.digcbt.com/dig/studyTest2/*` | 対象の問題ページへのアクセス |

## 開発

Node.js 24以降とPython 3を使用します。

```sh
npm ci
npm run check
npm test
npm run package
```

配布用ファイルは `dist/Testudy-fuck.zip`、展開済みの拡張は `dist/Testudy-fuck/` に出力されます。ZIPには拡張の実行ファイル、アイコン、README、ライセンスのみを含めます。

テストは問題画面・Chrome APIの模擬環境で実行します。ローカルの解析データを使用する追加テストは、そのデータがない環境ではスキップされます。HAR、教材データ、解析したサイトのソース、試聴用音声は公開対象に含めません。

変更や不具合報告については [CONTRIBUTING.md](https://github.com/b4mbo-o/testudy-fuck/blob/main/CONTRIBUTING.md) を参照してください。
